# 产品迭代路线

## 1. 状态规则

里程碑和功能只允许使用以下状态：

- `未开始`：尚未进入实施。
- `进行中`：已获得授权并开始实施。
- `受阻`：缺少必要输入、能力或外部条件。
- `已完成`：全部退出条件和验收标准已经通过。

编写完成不等于已完成。没有验证结果时不得将状态改为 `已完成`。

## 3. M0：产品基线

### 目标

建立后续 AI 和开发者能够直接使用的产品依据，不实施 Skill 或操作飞书资源。

### 交付范围

- `.ai/README.md`
- `.ai/DECISIONS.md`
- `.ai/PRODUCT.md`
- `.ai/ROADMAP.md`
- 当前会话可见的飞书 MCP 云文档能力快照
- 产品功能、效果、原因、优先级和验收标准

### 退出条件

- 个人版、飞书中国版和 MCP-only 已明确。
- 默认用户身份且禁止自动降级已经明确。
- 禁止默认使用 Chrome 等替代通道已经明确。
- 强制预览、冲突检测和回读验证已经明确。
- 高风险操作默认关闭已经明确。
- 所有主要资源都有产品能力定义。
- 产品资料之间没有相互冲突。

### 实施范围

- 创建 `SKILL.md`，只负责触发、资源路由和安全边界。
- 创建公共参考文档：MCP 能力、身份策略、预览协议、安全策略、质量规则。
- 实现链接与资源类型识别。
- 实现运行前 MCP 能力检查。
- 实现 `analyze`、`preview`、`apply`、`verify` 模式。
- 实现 `preview_id`、目标指纹、冲突检测和幂等规则。

### 不包含

- 不实现完整文档排版。
- 不实现复杂电子表格或多维表格业务。
- 不开放危险操作。

- 模拟 MCP 测试证明只读与预览模式零写入。
- 模拟失败证明不会切换应用身份或其他通道。
- 使用指定测试文档完成一次受控的读取、预览、确认、局部写入和回读验证。

### 退出条件

- AC-01 至 AC-11 适用于基础闭环的部分全部通过。
- 安全规则已同时存在于文档、`SKILL.md` 和测试中。

### 危险操作门槛

删除、转移所有者和公开权限修改只有满足以下条件后才能实施：

1. 用户明确要求开启对应功能。
2. 产品决策记录已更新。
3. 本地配置开关已开启。
4. 已生成独立高风险预览。
5. 用户完成二次确认。
6. 已准备可行的恢复或补救方案。

## 10. 测试策略

### 单元测试

- 飞书链接与资源类型解析。
- 操作模式和身份参数选择。
- 差异计算、预览编号和状态指纹。
- 表格范围和多维表格业务主键。
- 模板生成和质量规则。

### 模拟 MCP 测试

- 只读和预览阶段零写入。
- 用户身份失败后零应用身份调用。
- 能力缺失后零 Chrome、CUA、OpenAPI 或其他连接器调用。
- 写入顺序满足“预检—执行—回读”。
- 部分失败结果得到准确汇报。

### 真实集成测试

- 使用专门的测试资源。
- 每次写入仍需生成预览并获得确认。
- 验证文档、电子表格、多维表格、知识库、云盘和妙记的实际权限与返回结构。
- 测试结束后不自动删除测试资源，除非用户另行确认删除预览。

## 11. 授权边界

里程碑授权只允许修改仓库内对应实现文件，不等于以下授权：

- 不等于允许调用真实飞书资源。
- 不等于允许执行任何远端写入。
- 不等于允许使用应用身份。
- 不等于允许调用 Chrome、OpenAPI 或其他替代通道。
- 不等于允许删除、转移所有者或修改公开权限。

真实飞书写入必须逐次遵守产品预览确认协议。
