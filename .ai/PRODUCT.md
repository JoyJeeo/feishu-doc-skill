# PRD：飞书云文档智能工作流 Skill

## 1. 产品摘要

本产品是个人使用的飞书云文档 Skill。用户提供飞书链接、原始材料和目标后，Skill 在当前已连接飞书 MCP 实际提供的能力范围内完成内容创作、结构整理、格式排版、数据处理和项目归档，并确保每次远端修改都可预览、可确认、可验证。

统一闭环：

```text
识别需求与资源
→ 检查飞书 MCP 能力
→ 使用用户身份读取
→ 理解现状并生成方案
→ 展示本地可查看的修改效果预览
→ 用户确认指定预览
→ 检查目标是否变化
→ 使用用户身份执行
→ 回读验证并汇报
```

## 2. 用户与问题

目标用户是当前仓库所有者本人，主要承担产品、项目、技术和知识整理工作。

需要解决的问题：

- 文档从零撰写、改写和排版耗时。
- 项目材料散落在文档、表格、知识库和妙记中。
- 数据整理与行动项维护存在大量重复操作。
- AI 直接修改协作文档容易误改、覆盖或重复写入。
- 飞书资源类型多，用户不应承担底层 Token、块结构和工具选择成本。

## 3. 目标与成功标准

### 3.1 目标

- 覆盖当前飞书 MCP 已暴露且通过验证的文档、电子表格、多维表格、知识库、云盘及其组合场景；妙记暂不纳入当前产品范围。
- 将内容生成、资源操作和安全验证组成一个一致工作流。
- 默认保护原有内容，只修改用户确认的范围。
- 让 MCP 能力缺失、权限不足和部分失败均可被准确理解。
- 建立可持续维护的产品模块和验收体系。

### 3.2 成功标准

- 只读与预览阶段没有任何远端写入。
- 没有有效 `preview_id` 时不能执行修改。
- 用户能够在本地预览中直接看清实际写入内容、前后差异和不受影响范围；`preview_id` 只负责绑定操作。
- 写入只影响预览中声明的目标和范围。
- 用户身份失败时不会尝试应用身份。
- MCP 缺少能力时不会调用 Chrome、OpenAPI 或其他替代通道。
- 写入后能够回读并验证结果。
- 重复执行同一预览不会重复创建内容或数据。
- 每项正式支持的资源能力都有可重复的集成测试。

## 4. 非目标

- 不支持 Lark 国际版。
- 不面向公开发布、多租户或跨客户端兼容。
- 不开发飞书 MCP 服务。
- 不更新、扩展或自定义飞书 MCP 来补齐 Skill 能力。
- 不直接调用飞书 OpenAPI。
- 不在用户确认前自动写入。
- 不通过 Chrome、CUA、网页模拟或其他连接器绕过 MCP 缺失能力。
- 不默认开放删除、转移所有者和公开权限修改。
- 不把飞书聊天、审批和日历等非云文档产品作为核心范围。
- 不承诺当前 MCP 没有提供的幻灯片、思维笔记或白板操作。
- 当前 MCP 未暴露的任何资源能力暂不纳入实现计划，也不作为里程碑阻塞项。

## 5. 假设与依赖

- 当前 Codex 环境已经连接可用的飞书 MCP。
- 用户能够完成飞书侧必要授权。
- 产品只编排 MCP 工具，不控制 MCP 服务内部如何实现。
- 默认知识库空间、父节点和云盘目录将在首次实现配置时提供。
- 真实写入测试将在独立测试资源中进行，并继续遵守逐次预览确认。

### 5.1 MCP 能力基线快照

截至 2026-09-09，当前会话可见的飞书 MCP 工具中包含以下云文档相关前缀：

| 资源 | 可见工具数量 | 当前判断 |
|---|---:|---|
| 飞书文档 `docx` | 21 | 包含文档及文档块读写能力 |
| 云盘 `drive` | 52 | 包含文件、评论、版本、导入导出和权限相关能力 |
| 电子表格 `sheets` | 27 | 包含表格、工作表、筛选和查找替换等能力 |
| 多维表格 `bitable` | 46 | 包含应用、数据表、字段、记录、视图、表单和工作流能力 |
| 知识库 `wiki` | 16 | 包含空间、节点和成员相关能力 |
| 妙记 `minutes` | 3 | 以获取内容、媒体和统计为主 |
| 白板 `board` | 1 | 仅观察到节点列表能力，属于部分支持 |
| 幻灯片 `slides` | 0 | 当前未观察到专用工具 |
| 思维笔记 `mindnote` | 0 | 当前未观察到专用工具 |

该表只表示工具元数据可见，未验证账号权限和真实调用结果，也不是永久能力承诺。每次执行仍需检查具体工具。

当前产品范围以本快照中“工具可见且真实可验证”的交集为准。未来 MCP 新增能力不会自动进入路线图，只有用户明确重新纳入后才实施。

## 6. 核心用户工作流

### 6.1 只读分析

识别资源、检查读取能力、使用用户身份读取并返回结论。不得创建 `preview_id`，不得调用写入工具。

### 6.2 创建资源

生成内容与结构，展示创建位置、完整内容和风险预览；用户确认后在指定位置或个人默认位置创建，并回读验证。

### 6.3 修改现有资源

读取当前内容，定位章节、区域、记录或节点，生成差异；确认后重新检查目标状态，只执行预览范围并验证非目标内容未变化。

### 6.4 项目整理

读取项目材料，规划知识库主页、项目文档、指标表格、行动项和风险台账。每种资源分别生成预览和确认，不使用一次笼统确认覆盖全部写入。

## 8. 交互与预览协议

### 8.1 操作模式

- `analyze`：只读分析，不生成待执行写入。
- `preview`：生成内容、差异和风险，不执行写入。
- `apply`：执行用户已经确认且仍有效的预览。
- `verify`：回读检查内容、结构和格式。

### 8.2 预览对象

```yaml
preview_id: 唯一编号
target: 目标资源及链接
resource_type: docx | sheets | bitable | wiki | drive | minutes | board
identity: user
operation: create | append | insert | replace | move | update | delete
scope: 章节、区域、记录或节点范围
before_fingerprint: 目标状态指纹
changes: 结构化差异
risks: 权限、覆盖、删除和格式风险
required_capabilities: 所需 MCP 工具能力
verification: 写入后的检查方法
```

### 8.3 确认规则

- 初始修改请求只授权生成预览。
- 结构化预览对象供系统绑定和校验；必须同时渲染为用户可在本地直接查看的效果确认单，不能只展示 `preview_id` 或编码参数。
- 用户必须在查看效果确认单后明确确认对应操作；`preview_id` 可用于追溯，但不要求用户手工理解或输入编号。
- 写入前重新读取目标并比较指纹。
- 目标变化、权限变化或目标改变时，原预览失效。
- 执行内容不得超过预览声明范围。
- 多资源修改分别预览。
- 同一预览不得重复产生副作用。

## 10. 权限、隐私与安全

- 支持用户身份的工具显式设置 `useUAT: true`。
- 不依赖 MCP 对身份参数的默认值。
- 用户身份权限不足时停止，不自动改用应用身份。
- 用户明确要求应用身份时，必须生成新的独立预览。
- 默认关闭删除、转移所有者和公开权限修改。
- 日志只记录资源类型、操作、范围、状态和错误，不记录完整敏感正文。
- 不在仓库中保存任何飞书访问凭证。
- 不认识的文档块或字段不得被静默删除。

## 11. 非功能需求

| NFR-05 | 失败信息可理解 | 错误输出包含阶段、目标、原因和未执行范围 |
| NFR-06 | 长文档和批量数据可分批处理 | 使用大样例验证分页、批次和部分失败 |

## 12. 边界情况与失败处理

| 情况 | 产品行为 |
|---|---|
| 链接无法识别 | 说明支持的资源链接类型，不调用任何远端工具 |
| MCP 工具不可见 | 报告缺失能力，不寻找替代通道 |
| 用户身份权限不足 | 报告权限不足，不降级应用身份 |
| 预览后目标变化 | 原预览失效，重新读取并生成预览 |
| 存在同名章节 | 使用标题路径、块 ID 和内容指纹定位；无法唯一定位时停止 |
| 批量写入部分失败 | 报告成功、失败和未执行项，不宣称整体成功 |
| 不支持的内容块 | 保留原块并提示，不静默删除 |
| 幻灯片或思维笔记无工具 | 仅报告当前 MCP 不支持 |
| 白板只有读取能力 | 只执行已验证的读取能力，不推断可写 |
| 用户要求危险操作 | 默认告知功能关闭；只有先开启策略后才能生成独立预览 |

## 13. 验收标准

- AC-01：`analyze` 和 `preview` 模式没有任何远端写入调用。
- AC-02：没有有效 `preview_id` 时拒绝执行写操作。
- AC-03：所有支持用户身份的调用显式使用用户身份。
- AC-04：用户身份失败后没有应用身份调用。
- AC-05：MCP 缺少能力时没有 Chrome、CUA、OpenAPI 或其他连接器调用。
- AC-06：本地可查看的预览包含目标、身份、操作、实际写入内容、范围、前后差异、不受影响范围、风险和验证方式；`preview_id` 仅作为内部绑定编号。
- AC-07：目标状态变化后旧预览无法执行。
- AC-08：写入只影响预览声明范围，非目标内容保持不变。
- AC-09：同一预览重复执行不会重复创建内容或记录。
- AC-10：写入后回读结果与预期一致。
- AC-11：部分失败被准确报告，不显示为全部成功。
- AC-12：删除、转移所有者和公开权限修改默认被拒绝。
- AC-13：未支持的幻灯片、思维笔记和白板操作只返回能力缺失。
- AC-14：个人配置和仓库文件中不存在访问凭证。

## 14. 风险

| 风险 | 处理方式 |
|---|---|
| MCP 工具名称或能力变化 | 运行前检查能力，不将工具数量作为产品承诺 |
| 权限与资源归属不符合预期 | 默认用户身份，写前权限检查 |
| Markdown 与飞书格式不完全对应 | 预览中说明格式损失，保留不支持块 |
| 产品文档与运行时脱节 | M1 将关键决策同步进 `SKILL.md` 和安全测试 |
| 默认目录配置错误 | 创建预览时展示实际目标路径 |
| 大批量修改难以完整展示 | 显示统计、影响范围和代表性差异，完整差异按需展开 |
