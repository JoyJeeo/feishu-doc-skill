# SPEC-M4-03：Wiki 与 Drive 写入预览

- 父项类型：产品需求
- 父项 ID：`M4`
- 状态：已完成
- 执行顺序：3 / 4
- 更新时间：2026-09-13

## 目标

实现当前 MCP 支持的 Wiki 节点与 Drive 文件操作预览、冲突检查、异步结果和回读验证。

## 范围

- FR-W03 至 FR-W05、FR-F02 至 FR-F04 的当前 MCP 可实现子集。
- 节点创建、复制、移动、改名和文档入库；文件夹创建、文件复制或移动、文档版本创建；导出仅验证任务创建与结果元数据。导入只在取得可验证的上传文件 Token 后验证；导出任务返回的 Token 已确认不能直接用于导入。

## 非目标

- 不上传本地文件，不删除资源，不修改所有权或公开权限。
- 当前 MCP 无导出文件下载工具，因此不宣称导出文件可下载、可打开或内容完整，也不将完整导出视为已验证能力。
- 当前 MCP 缺少上传分片工具，无法自行产生可验证的上传文件 Token；导出任务 Token 的导入请求返回 `1069910`，未产生新文档。

## 依赖与验收

- 依赖 `SPEC-M4-02` 完成并获用户验收（2026-09-12）。
- 每个远端写入使用独立确认预览，在专用测试资源完成回读和人工验收。
- 普通 `.docx` 文件 Token 的导入已完成技术验证：异步任务成功，源文件保留，新在线文档的标题、类型、位置、纯文本和表格结构均已回读。
- 用户于 2026-09-13 检查导入后的真实在线文档并明确回复“本步验收通过，继续”；本 Spec 已完成。
