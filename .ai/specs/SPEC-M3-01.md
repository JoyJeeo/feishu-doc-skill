## 目标

盘点当前 Sheets 与 Bitable MCP 工具，确认 M3 各需求的可实施边界、顺序和真实验收依赖。

## 范围

- 核对当前 `mcp__feishu__sheets_` 与 `mcp__feishu__bitable_` 工具清单和用户身份参数。
- 确定 Sheets 与 Bitable 的最小读取、预览、写入和回读链路。
- 将 M3 拆成有序、独立验收的 Spec。
- 把已确认的能力缺口写入运行时 MCP 路由参考。

## 非目标

- 不实现表格或多维表格业务逻辑。
- 不调用真实飞书资源，不生成远端写入预览。
- 不使用应用身份或任何非飞书 MCP 通道。
- 不提前实施 `SPEC-M3-02` 至 `SPEC-M3-05`。

## 依据与结论

- 当前可见 27 个 Sheets 工具，覆盖电子表格元数据、工作表、限定范围查找替换、筛选和浮图等能力。
- 当前没有任意区域值读取或写入工具，因此 FR-S02 至 FR-S04 暂无安全实现链路。
- 当前可见 46 个 Bitable 工具，核心元数据、表、字段、记录查询、单条与批量创建更新工具齐全。
- Bitable 元数据支持用户身份；创建接口支持 `client_token`，但真实权限和返回结构仍未验证。

## 验证

- 通过当前工具元数据核对 Sheets 27 个、Bitable 46 个工具。
- 核对 Sheets 元数据、工作表、查找和替换接口的参数结构。
- 核对 Bitable 元数据、表、字段、记录查询、创建、更新与批量接口的参数结构。
- 全量本地测试、Skill Creator 结构校验和 `git diff --check` 通过。

## 验收标准

- 不把工具可见性描述为真实权限或集成成功。
- 明确记录 Sheets 任意区域读写缺口，且不设计替代通道。
- Bitable 实施链路包含完整分页、业务主键匹配、字段类型校验、幂等参数和写后回读。
- 后续每个 Spec 都有独立范围、依赖、验证和授权门禁。
