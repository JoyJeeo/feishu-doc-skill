# SPEC-M2-04：真实文档集成验收

- 父项类型：产品需求
- 父项 ID：`M2`
- 状态：未开始
- 用户授权：未授权
- 执行顺序：4 / 4
- 更新时间：2026-09-12

## 目标

使用专用飞书测试资源验证 M2 的文档创建、结构回读、章节级编辑、幂等保护、格式风险报告和只读质量审计，并完成父项验收。

## 范围

- 通过用户身份读取专用测试资源并生成具体预览。
- 在逐次确认预览后验证完整文档创建和指定章节局部修改。
- 回读结构、目标范围和非目标范围，验证重复执行保护。
- 运行只读质量审计并确认没有写调用。

## 非目标

- 不读取或修改未指定资源。
- 不使用应用身份或非飞书 MCP 通道。
- 不自动清理测试资源；删除仍保持关闭。

## 依赖

- `SPEC-M2-01` 至 `SPEC-M2-03` 已完成并经用户确认。
- 用户提供专用测试文档或目录，并授权只读检查。
- 每次真实写入均有独立预览和对应 `preview_id` 确认。

## 交付物

- 真实 MCP 调用的受控验证证据。
- M2 父项验收结果、路线图和状态更新。

## 验证与验收

- 创建后的标题、块层级和内容回读一致。
- 章节编辑只改变预览声明范围，非目标章节不变。
- 重复执行同一预览不会产生新副作用。
- 格式不能保真时预览和结果均准确报告。
- 审计模式零写入；M2 退出条件全部有证据后才标记完成。
- 全部真实效果已向用户展示并获得人工验收。
