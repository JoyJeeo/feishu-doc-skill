# SPEC-M3-05：电子表格区域能力与 M3 验收

- 父项类型：产品需求
- 父项 ID：`M3`
- 状态：未开始
- 路线图归属：已移出当前 M3 执行映射，不作为退出条件
- 范围调整：用户于 2026-09-12 明确要求 Skill 仅实现当前 MCP 能力，其他能力暂不考虑
- 更新时间：2026-09-12

## 目标

保留原候选范围记录；当前不实施。即使 MCP 将来提供任意区域值读取和写入，也必须由用户明确重新纳入路线图后才能启动。

## 范围

- FR-S02 至 FR-S04，以及 FR-S10 的完整区域差异能力。
- 空值、重复值、异常格式、日期、状态、名称和数值的可解释转换。
- 指定区域写前冲突检测、写后目标与非目标验证。

## 非目标

- 不使用其他连接器、浏览器自动化或 OpenAPI 补齐能力。
- 不提前实现 FR-S06 至 FR-S09。

## 依赖

- `SPEC-M3-04` 完成并获用户验收。
- 当前飞书 MCP 出现可用的任意区域值读取和写入工具，并支持用户身份。
- 用户明确重新评审并将本 Spec 纳入路线图。

## 交付物与验收标准

- 区域模型、清洗与标准化规则、预览门禁、测试和真实人工验收证据。
- 指定区域之外的单元格不变；转换数量和规则可解释；公式和字段类型不被意外改变。
- 本文件当前不是活跃 Spec，不参与 M3 父项退出判断。
