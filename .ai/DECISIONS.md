# 产品决策记录

本文件记录已经确认、后续实现不得静默改变的产品决策。状态为“生效”的决策具有约束力；调整决策必须获得用户明确同意，并同步更新产品设计与路线图。

| 编号 | 状态 | 决策 | 原因 | 对实现的影响 |
|---|---|---|---|---|
| D-001 | 生效 | 产品仅服务当前个人用户 | 优先满足个人真实工作流，不承担公开分发成本 | 可以使用个人默认目录、模板和术语配置，不设计公开安装与多租户能力 |
| D-002 | 生效 | 只支持飞书中国版 | 产品范围已经明确 | 不适配 Lark 域名、账号体系和国际版差异 |
| D-003 | 生效 | 一个仓库覆盖飞书云文档全家族 | 文档、数据和知识结构需要组合使用 | 在一个入口下拆分文档、电子表格、多维表格、知识库、云盘、妙记等模块 |
| D-004 | 生效 | 所有飞书远端操作只通过飞书 MCP | 当前环境已有飞书 MCP，避免维护第二条传输链路 | 不实现直连飞书的客户端，不在本地脚本中发送飞书请求 |
| D-005 | 生效 | 不调用飞书 OpenAPI | 避免重复处理鉴权、HTTP、限流和接口兼容 | MCP 缺少能力时报告缺失，不通过 OpenAPI 补齐 |
| D-006 | 生效 | 默认使用用户身份 | 个人助手的权限、归属和审计应与当前用户一致 | 支持时显式设置 `useUAT: true`，不依赖工具默认值 |
| D-007 | 生效 | 不自动降级到应用身份 | 自动切换会改变权限边界和操作主体 | 用户身份失败时停止并说明；只有用户明确指定后，才能为应用身份生成独立预览 |
| D-008 | 生效 | 未经用户明确要求，不使用 Chrome 等替代通道操作飞书 | 保持操作路径可控、可审计 | 禁止自动调用 Chrome、浏览器自动化、CUA、其他连接器或网页模拟操作飞书 |
| D-009 | 生效 | MCP 不支持时只报告，不寻找替代通道 | 能力缺失比隐式绕过更安全 | 返回缺失能力和未执行结果，不伪造成功，不建议自动兜底 |
| D-010 | 生效 | 所有飞书写入必须先预览再确认 | 防止误写、误删和范围失控 | 初始修改请求只授权生成预览；执行需要确认对应 `preview_id` |
| D-011 | 生效 | 写入前重新检查目标状态 | 多人协作文档可能在预览后变化 | 状态指纹变化时使旧预览失效并重新生成 |
| D-012 | 生效 | 写入后必须回读验证 | MCP 返回成功不等于业务结果正确 | 通过飞书 MCP 重新读取，并比较预期范围、内容和结构 |
| D-013 | 生效 | 删除、转移所有者和公开权限修改默认关闭 | 这些操作难恢复或会扩大数据暴露范围 | 默认直接拒绝；未来开启后仍需独立预览和二次确认 |
| D-014 | 生效 | 幻灯片、思维笔记或白板能力缺失时仅报告不支持 | 当前 MCP 对这些资源的支持可能为空或不完整 | 按具体操作检查工具，不以其他资源类型或浏览器代替 |
| D-015 | 生效 | 一个 `SKILL.md` 入口，内部拆分资源适配和工作流 | 避免单文件过大并便于独立测试 | `SKILL.md` 只负责触发、路由和边界，详细规则按需读取 |
| D-016 | 生效 | 支持个人默认知识库和云盘目录 | 减少每次创建时的重复选择 | 默认位置写入本地非敏感配置；用户指定目标时以本次指令为准 |
| D-017 | 生效 | 跨资源项目操作分别预览 | 一个项目可能同时修改多种资源 | 文档、电子表格、多维表格、知识库等分别展示目标和影响范围 |
| D-018 | 生效 | `.ai` 是产品依据，不是运行时保障 | 产品文档本身无法约束工具调用 | 实现 M1 时必须将身份、通道和预览规则同步写入 `SKILL.md` 与测试 |

## 重新评审条件

只有出现以下情况时才需要重新评审相关决策：

- 用户明确改变个人版、飞书中国版或 MCP-only 的产品方向。
- 当前飞书 MCP 被替换，身份语义或工具能力发生实质变化。
- 用户希望开放默认关闭的高风险操作。
- 新资源类型获得稳定 MCP 能力，需要纳入正式支持范围。
